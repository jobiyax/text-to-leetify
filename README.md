Outil open source qui convertit du texte en Leet Speak (1337) en remplaçant les lettres par leurs équivalents les plus courants tout en conservant le texte lisible.

## Fonctionnalités

- Conversion automatique du texte en Leet Speak (1337)
- Texte conservé lisible
- Open source, gratuit

## Table de conversion

L'outil remplace les lettres par leurs équivalents leet :

| Lettre | Nombre leet |
| ------ | ----------- |
| A      | 4           |
| B      | 8           |
| E      | 3           |
| G      | 6           |
| I      | 1           |
| L      | 1           |
| O      | 0           |
| S      | 5           |
| T      | 7           |
| Z      | 2           |

## Utilisation

```bash
uv run python main.py
```
